# 独立代码审查记录

日期：2026-10-21。独立审查对象：本分支完整实现、设计、计划和实施调整。审查以只读方式进行，未修改源文件或生成环境。

审查发现两项 Important，无 Critical：

1. 教学列表和详情读取预约时仍使用原共享客户端。旧账号的延迟401可能清除新账号登录状态。已将两处读取改为教学专用客户端，并覆盖旧401到达新会话后的回归测试；小程序下载错误分支也先核对请求所属身份。
2. 上传组件移除文件仅修改本地数组；重新打开草稿时服务器会恢复全部未绑定文件。已增加临时附件移除接口，在同一事务内验证所有权、预约状态和未绑定状态后删除，组件成功后才移除本地行。删除失败可重试，已发布课件和历史作业禁止删除。测试覆盖越权拒绝、草稿重新读取，以及浏览器保存、离开、重新进入后仅发布保留文件。

两项均先观察新增回归测试失败，再实施修复。浏览器验证进一步发现 uni-app 的空 DELETE 请求被 JSON 解析器拒绝，已通过显式发送空对象修复；个人目录的后端副本显式允许 PUT、DELETE 跨域方法。

独立审查者未重新执行完整套件、外观或崩溃测试；修复后的验证由实施方执行，实际结果见 VALIDATION.md 与 validation-results.json。未请求第二轮独立审查。用户功能审核及主项目集成审批仍待进行。
