# 项目需求调查与 MVP 范围（2026-10-11）

## 来源与确认状态
依据仓库 README.md、docs/ARCHITECTURE.md、docs/ROADMAP.md 和 CONTRIBUTING.md 整理。本文件是内部需求梳理，不等于比赛官方规则；比赛名称、评分标准、提交材料、截止日期须由团队补充官方通知后确认。

## 核心用户与问题
- 学生/家长：找到合适的家教、比较科目与授课方式、提交预约意向、追踪状态。
- 大学生家教：展示可核验的基本信息、申请入驻、管理接单意向。
- 管理员：审核资料、处理异常与投诉（后续）。

## 建议演示主线
家长搜索老师 → 筛选/查看详情 → 提交模拟预约 → 查看预约状态；大学生提交模拟入驻资料 → 管理员展示审核状态（后半段尚未实现）。

## 非目标与风险
- 当前不提供真实匹配、认证、付款或消息通知。
- 不采集真实未成年人敏感资料，不上传密钥和真实用户个人信息。
- 真实上线前须完成权限、隐私政策、监护人同意、投诉与数据删除机制。
