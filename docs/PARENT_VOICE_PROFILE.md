# 家教资料与家长语音匹配（2026-10-22）

本批集成 #28 的照片上传和自述教学资料，保留 #27 的小书灵与订单地图。#29 的目标由本批完成，未直接使用其关键词交叉匹配实现。

## 家教端

- 入驻 / 编辑资料的个人简介为 10–1000 字；草稿可为空，超过1000字不可保存。前端、Mock和后端一致，旧资料无须迁移。
- 个人定位复用西安地图，可点公共地点或地图任意点。保存的是最近的公共服务片区名称（原 `area` 字段），不是点击点的精确经纬度；提交后经原审核流程公开并参与片区距离估算。手填地区仍保留。H5可主动点击“定位到附近公共片区”请求浏览器定位权限，坐标仅在本机换算片区；拒绝或不支持时手选。没有自动收集定位。
- 照片选择支持相册/相机，先保存草稿即可上传。API 限 JPG/PNG/WebP、2MB，压缩为512像素以内JPEG并移除元数据；本人和审核员可预览，通过审核才公开，更换照片需重新审核。照片目录和数据库一起备份。小程序真机相机交互尚未验证。

## 100分匹配

默认权重：学科35、上课时间30、教学经验20、费用10、其他5。学科、预算、方式与用户所选距离仍是硬条件。可以调整权重并恢复默认；调整后的整数分配采用最大余数法，使各项满分合计恰好100。

- 学科：通过硬筛选后得到该项分数。
- 时间：解析同一条声明内配对的星期和时段，不把“周六上午、周日下午”误当“周六下午”。精确时间如“周六14:00–15:00”需被老师声明时间完整覆盖；宽泛“下午”只要求有交集，并注明具体钟点待双方确认。时间灵活、否定或不确定的复杂声明不加分。家长输入是多个可选时段时，有一个吻合即可。
- 经验：自述月数 / 36，封顶1；缺失为0。
- 费用：`max(0, 1 - 课时费 / 预算)`。
- 其他：课程成绩/100、教学能力/5、案例数/10（各项封顶1）、偏好命中率四项的平均值；缺失为0。

每项分数为 `round(该项分配满分 × 比例)`，推荐理由逐项展示。同分按片区参考距离、价格、ID排序。自述资料与合成演示数据不能作为资质或教学效果核验。

## 小书灵语音问答

1. 首页或其他页面点击右下角“小书灵”进入独立问答页。
2. 可以打字，或点击“语音提问”。浏览器首次请求麦克风权限，识别为文字后发送；打开“语音朗读”后读出答复。
3. 说“请帮我匹配初中数学，预算100元，线上，周六下午”，会整理条件、进入智能匹配并读取当前数据源的公开老师生成规则推荐。缺失科目、年级或预算时提示补充。此命令只查询推荐，不创建预约。
4. 说“平台怎么使用”或“怎么查看订单地图”获得指引。照片、订单、定位均不随对话自动发送。

语音输入使用浏览器的 SpeechRecognition / webkitSpeechRecognition，语音输出使用 SpeechSynthesis；需要浏览器支持和麦克风权限，通常要求HTTPS或localhost。浏览器供应商可能联网处理音频。当前不包含自建ASR、微信录音转写或嘴型驱动；不支持时可继续文字问答。页面离开或清空时停止收音和朗读，忽略迟到结果。

服务端配置 `MATCH_MODEL_*` 后支持模型问答，否则明确显示“本机演示·非大模型”。语音识别、明确命令识别和规则推荐不冒充大模型。真实供应商模型、实际麦克风/音箱与微信真机尚未实测，浏览器自动化通过模拟语音接口验证流程。

## 启动

仓库根目录 `npm ci`；`server/` 执行 `npm ci`、`npm run db:generate`。按 `DEMO_GUIDE.md` 初始化开发数据库和账户，再运行API与H5。纯本机演示可在根目录直接 `npm run dev:h5 -- --host 0.0.0.0`。问答路由为 `/#/pages/assistant/index`。
