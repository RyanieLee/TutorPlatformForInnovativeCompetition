## 修改边界

- H5 条件导入 `confirmed-web.css`，桌面视觉覆盖宽度至少 768px 的网页，并为更小窗口提供同风格适配；1600px 已确认版面保持不变。
- 新增首页两个桌面卡片只复用已有导航函数，小屏也保留同功能入口，不新增服务调用。
- 不替换或删除原 SVG 素材，不改人物动作和表情控制代码。
- 保留减少透明效果、高对比度和打印处理。
