# 教学闭环演示

Node.js20及以上，仓库根目录npm ci、npm run dev:h5，打开终端本地地址（通常http://localhost:5173）。默认Mock无需密钥，在当前浏览器保存计划和报告，不跨设备同步。重新演示请另建虚构预约，不清空原记录。API模式沿用DEMO_GUIDE双终端步骤，npm run db:migrate新增教学表，不用db:reset升级旧库。

## 5至7分钟录屏顺序

1. 家长选择小林老师创建数学预约，称呼使用虚构案例；家教接受，先不要标记完成。
2. 预约详情进入“教学计划与课后反馈”，加载预置课程，展示四节45分钟课程。展开第一课目标、x+7=15例题、练习答案和作业；可编辑课程并保存草稿。
3. 切家长确认草稿不可见；返回教师，勾选核验课程与答案，确认发布v1。
4. 展开第二课5道题，填入虚构3/5记录，核对Q1—Q3正确、Q4/Q5错误及移项符号错因，保存事实。60%只是本次5题计算，不代表教学提升。
5. 生成明确标注的样例反馈，展示3/5、Q4/Q5与教师观察证据。可编辑家长短报告，保存后确认发布。
6. 生成第三课样例调整建议，对比原版与建议：增加10分钟符号专项，去分母推迟至后续补充课，总时长仍45分钟。确认采纳仅生成新草稿，此时家长仍看到v1。
7. 教师核验发布v2，家长查看新课程及确认报告；切回v1并刷新，证明历史保留、数据持久。

模型复用后端MATCH_MODEL_*配置，仅由后端调用。未配置或失败时选“加载预置演示课程/生成样例反馈/生成第三课样例调整建议”，不会冒充真实调用。API密码使用本机server/.env，不写入本文或截图。真实供应商、公网、微信真机须分别验收。

## 异常恢复

网络结果未知时暂停新操作，使用“重试上次提交”保留同一请求ID，或刷新确认；409须核对最新状态，不覆盖其他窗口。修改课堂事实后须重新生成并确认反馈，旧建议不能用于新事实。取消或完成预约保留可读历史，不能新增教学操作。

样例修订仅适用于第二课Q4/Q5均错误且教师记录移项符号错因的场景；其他情况需手工备课或另行验证模型建议。现有课件及作业页面保留，闭环不做OCR、自动批改、支付或实时视频。
