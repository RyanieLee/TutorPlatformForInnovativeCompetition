### 修复的用户可见问题

Mock 以前只寻找“已批准的申请”，当家教修改已通过资料并保存为草稿时，会重新显示旧种子家教；首页、详情和推荐仍可看到这个已经撤回的家教，与开发 API 不一致。

现在首次未操作时仍保留种子演示。进入申请流程后，草稿、待审和驳回状态都不再公开该演示家教；审核通过后展示审核后的资料。撤回后不能创建新预约，已有预约保留，家长仍可查看。

### 自动验收补充

- 预约创建 → 家教接受 → 家长查看 → 家教完成 → 家长查询和刷新。
- 提交资料 → 管理员批准 → 家教退回草稿 → 首页与推荐撤下 → 重新提交/批准 → 首页恢复。
- 资料撤回及恢复不删除已有已完成预约。
- API 桌面与手机项目各使用独立 API 进程及临时 SQLite 数据库，避免测试之间共享数据和登录限流状态；没有调整应用的认证或限流规则。
- Prisma 客户端在 E2E 启动前只生成一次，避免多个 API 实例同时生成同一客户端。
