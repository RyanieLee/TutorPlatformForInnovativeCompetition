# 操作与按钮优化第一版

用户批准操作树后要求制作第一版：删除背景大人物，放大按钮和字体，主要动作居中，高级功能默认折叠。校园蓝绿玻璃风格、教师照片和右下角小书灵继续保留。

- 首页只保留找家教与学习中心两个主要动作，以三步说明卡解释服务链。
- 顶部：首页、找家教、AI学习中心、我的学习、我的、评委演示；登录家教或管理员时，学习入口按角色进入原工作台。
- 找家教页将智能匹配与自主筛选归在一起。原搜索、价格、方式、分页与教师详情逻辑抽为 TutorDirectory；返回页面刷新时保留筛选状态。
- 我的学习沿用原预约页，保留预约对应的教学计划、反馈与课次作业，增加订单地图入口。
- 匹配页的位置地图、权重、评分规则，以及学习页的官方资料、出卷高级参数、导出打印，默认折叠且可重新展开。状态留在原页面，业务服务与权限校验不变。
- 主要按钮约 56–64px 高、18px 字体；普通按钮至少48px、16px。小屏导航14px。正文、题目与答题选项保留适合阅读的对齐。

验证：TypeScript 与 H5 构建通过，18个文件110项单元测试通过。浏览器实点：首页找家教→自主筛选→教师详情；匹配高级设置展开/收起；学习中心→3题示例练习。1600px和390px首页无横向溢出；主按钮实测18px字体、约64px高。现有端到端脚本已按新的入口和折叠操作更新，本机未运行完整API/端到端矩阵，待CI验证。

本轮为第一版预览，单独提交草稿PR，未自动合并main。预览继续使用已公开的原网址，保留Mock演示来源说明。
