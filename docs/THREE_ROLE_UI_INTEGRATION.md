# 三端 UI、地图与课次集成

本分支基于 main `9060a92`，融合本地第三版视觉：书页式中文标题、墨绿粗细边框、柔和环境背景、局部通透叠层与减少动态效果支持。家长首页保留当前 main 的 24 位虚构家教、搜索筛选、预约入口；匹配页继续使用西安地图、片区按钮、需求解析与公开推荐理由。首页教学卡片可翻面，但不改动业务匹配规则。

家教与管理员工作台共用同一字体、面板、状态和控件体系，审核与举报权限仍由既有服务控制。家教的预约详情、家长的预约列表接入 `feat/chunxiaruo-lesson-homework-review` 中的“课次与作业”，并将该分支 `workspaces/chunxiaruo-commits/teaching/overlay/` 的前端页、接口、Prisma 模型、迁移和上传模块逐文件移入主工程。保留管理员默认不可读取学生作业的后端权限。Mock 模式显示明确的不可上传提示；实际收交需要本地 API 和持久存储。

没有覆盖 #22 的学习中心分支；它当时仍是独立 PR。另一个人的更新如继续变化，合入前需重新同步并跑检查。

## 已执行验证

- 前端类型检查通过，前端 63 项测试通过；家教与管理员工作流类型检查及 9 项测试通过。
- 后端 Prisma 客户端生成、TypeScript 编译和 80 项测试通过，测试迁移包含新教学表，附件/课次/提交相关 26 项通过。
- H5 与微信小程序构建通过。桌面 1440px 和手机 390px 的首页、地图匹配、家教工作台、管理员工作台、课次页截图检查无页面脚本错误和横向溢出。
- `npm run test:demo` 首次启动、预约、审核、举报、备份等真实 HTTP 流程运行到重启阶段；同一 Windows 测试进程重新执行 `db:init` 时，Prisma 尝试替换仍被该进程占用的引擎 DLL，报 `EPERM`，后续重启与恢复断言因此未完成。前述服务端测试使用隔离 SQLite 与 Fastify 注入请求，不能替代完整浏览器 API 验收。

截图和检查结果在 `docs/screenshots/campus-ui/`。在线底图依赖 Esri 网络服务；断网时可使用片区按钮。未验证微信真机、真实模型供应商或公网部署。本分支使用虚构资料，不处理真实学生资料。
