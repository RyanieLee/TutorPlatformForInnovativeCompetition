# 家长端补缺交付

基于已通过 CI 并合并的 #12（c3ecdf1），对应任务 #13，分支 feat/parent-api-delivery。

- ParentLayout 统一首页、详情、预约、订单和个人中心的品牌/导航/角色入口，不修改 B 工作台、全局路由和认证契约。
- 首页使用桌面三列、中等宽度两列、手机单列家教卡片；保留 loading、空列表、错误与重试、分页及 AI 入口。
- 价格上下限独立可空，范围 0–2000 元，最多两位小数，包含边界；可与关键词/科目/方式组合；按“应用价格”生效，无效输入保留上次条件并给出提示，支持重置。
- 可选 minPrice/maxPrice 通过 TutorQuery 传入 Mock/API；两者都先过滤后分页。API 针对整数报价向上/向下归整筛选边界，80.01 元下限不会误包含 80 元老师。
- API 未登录提示改为提交后存入开发服务器数据库；预约表单展示元/小时与授课方式，提交中禁用按钮；取消确认区分本机/API 模式。

验证：前端类型检查及 44 项单元测试通过；四项目 E2E 共 10 项适用用例通过，2 项仅 API 故障用例在 Mock 中跳过；服务端 19 项测试通过。首次新增小数边界测试发现 Prisma Int 字段截断问题，已用数学上下界修复后重跑通过。双模式 H5/小程序构建结果以本 PR 最新 CI 为准。
