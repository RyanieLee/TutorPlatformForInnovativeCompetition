# 西安地图与 AI 匹配演示

本批在 #19 后端筛选、统计、备份恢复基础上增强家长匹配入口。

## 直接体验

启动 Mock H5：`npm ci && npm run dev:h5`；首页点击“AI 家教匹配”。

1. 选择“高新 · 物理专题”等场景，或输入 6–160 字学习需求。
2. 点击“解析需求”，核对识别的科目、年级、预算和方式，点击“确认并填入表单”。
3. 在西安市地图点击公共参考点，或选择下方片区；选“线下”后可限定 5 / 10 / 20 km。
4. 生成推荐，查看过滤统计、评分原因和片区距离，再进入原详情/预约流程。
5. 刷新后保留本机位置；“清除位置”后刷新不再恢复。

## AI 的实际边界

- API 已配置模型时调用 #16 的服务端模型接口，仍要求家长登录，并由用户确认后应用建议。密钥不进入前端。
- Mock、API 未配置模型或状态不可读取时，明确显示“本机关键词解析（非大模型）”。关键词解析只提取有限明确字段，缺失或多科目歧义留空；不会伪造供应商调用。
- 模型请求失败会显示错误，不把本机解析伪装成模型成功。父母点位不加入模型请求或预约数据。
- 最终推荐继续使用硬过滤与公开评分公式；距离不加分，同分优先近处片区，再按价格/ID排序。线上不按位置限制。年级仅作需求摘要。

## 地图与位置

H5 使用 Leaflet 和 Esri World Street Map 在线底图，保留服务商及数据来源归属；当前公开瓦片接口无需前端地图密钥。演示在线服务受供应商可用性和使用条款约束，未下载或缓存离线瓦片。底图不可用时显示提示，12 个公共片区按钮与矢量标记继续可用。微信小程序当前提供同样的片区按钮选点，交互底图仅在 H5；小程序编译不代表真机地图验收。

位置使用 WGS84，仅接受演示范围内的西安主城区/近郊参考点；不是完整行政边界校验。点位存于 `tutor-platform:parent-location:wgs84:v1`，不自动获取 GPS，不请求定位权限，不上传到本项目 API 或模型。在线瓦片服务仍能看到地图视野所需的瓦片请求。

家教没有真实住址。资料 area 先匹配公共片区，同区未知地点退到该区首个公共参考点；完全无法识别的片区显示“无法估算”，并从有半径限制的结果中排除。距离为球面直线估算，不是上门路线、通勤时间或真实教师位置，不宜作为严格服务范围判断。

## 合成数据库

`server/prisma/demo-tutors.json` 是 Mock/API 共用的 24 份合成资料：五个科目、三种授课方式，65–150 元场景报价，包含不同专业、教学思路、可用时间和西安片区。

人物、履历、课时费和时间均为虚构；真实高校/地名只用于构造城市场景，学校名称以“（场景）”标注，不表示就读、合作、资质或背书。没有编造真实交易、评价、提分、用户数量或学校合作证据。

API `db:init` 补齐缺少的种子；已有 profile/application 均不覆盖，所以旧库首位老师可能仍保留原有资料。`demo.tutor` 管理第一份资料，其余 `demo.catalog.*` 目录账户使用随机不可公开密码，无公共登录凭据；所有记录继续受权限和公开审核状态约束。重新初始化不会复制资料或删除已有预约。只需重复 `npm run db:init` 即可给旧库增加目录，勿为更新演示而重置已有业务数据库。

## 验证

单元测试覆盖坐标校验/损坏存储恢复、清除、距离对称性、线下范围过滤、缺失片区排除、线上不受位置影响、同分附近优先，以及合成资料完整性和离线解析边界。浏览器用例覆盖 Mock/API 桌面/手机、瓦片断网、地图自由点击、片区选择、需求确认、附近结果和位置刷新/清除。真实供应商模型和微信真机仍需相应配置另行验收。
