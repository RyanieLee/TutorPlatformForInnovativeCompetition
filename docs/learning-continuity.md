# 云伴学：学生学情档案与持续教学

本轮在 PR #39 的绿色/Jenny双主题基础上开发，保留现有模型接入、图片批改、文字批改、课次与不可变作业记录。功能分支 `feat/student-learning-continuity`，不直接合并 main。

## 如何体验

1. 家长在“我的预约 → 学生档案与授权”或顶部“学情档案”建档。同名学生拥有不同 ID；家长主动选择预约，平台不按姓名合并历史。
2. 教师接受预约，在“学生学情与试课”提交具体试课观察。此时只见基本需求。
3. 家长确认试课，再明确授权摘要或学习详情，选择1—90天有效期；支持撤销。摘要开放已确认报告和交接快照；学习详情另外开放分析、训练。关联预约取消或结束后教师的云档案详情授权失效。
4. 家长在“作业与训练”选择进行中的预约，输入题目、作答、参考答案。真实作业页可带入提交编号，服务端核验原提交的家长及预约归属，不自动读取附件内容。
5. API 模式由管理员启用模型，家长明确同意发送脱敏学习文字后，生成结构化分析与针对训练。也可选择明确标记的固定分数加法示例。示例不是用户本次题目的实时分析。
6. 对应教师可更正分析、教学建议、训练题和参考答案，再确认。家长提交整轮训练；教师结合实际答案整理、编辑并确认备课报告。报告不提供虚构掌握率或提分结论。
7. 教师点击“用于下一课草稿”，将报告导入原课次编辑页；填写上课时间并核对预习、作业后自行保存发布。导入不会自动创建或发布课次。
8. 家长选择已确认报告保存交接快照，可同时撤销旧教师授权。新教师的预约也需明确绑定、试课、确认和授权。原课次资料仍遵循原权限；撤销云档案不能擦除教师先前合法获得的资料。

教师可在学情总览查看报告、训练与可核对的教学观察，并更正自己记录的观察。平台不推断学生性格或给学生贴能力标签。

## 沟通与通勤

预约双方可在“预约沟通与通勤”发送文字、手动刷新和读取早期记录；无关账户和管理员不可读双方私信。预约结束后只读，不提供推送通知。

通勤沿用西安公共片区参考点，只展示直线距离；地图按钮将选定公共坐标交给百度地图查询实际路线。平台没有实时路况、公交耗时或精确住址导航数据。

## 数据与模型

- 新增 StudentArchive、ArchiveBooking、BookingMessage 三张表及两次增量迁移。原课次、提交和附件不改写。按现有部署流程执行 `npm run db:generate`、`npm run db:migrate` 后启动服务端。
- 档案按家长归属持久化，所有命令校验 expectedRevision、requestId；重试同一请求必须保持内容相同。模型等待结束后重新验证会话、预约、授权与版本。列表仅返回简要卡片，详情按当前权限投影。
- 模型复用管理员加密保存的配置；关闭配置阻止新分析。结构化分析有独立上限（1800 tokens、6500字符），普通聊天仍为700 tokens、3000字符。只发送本次题目、作答和参考答案，不发送学生档案身份、地址或完整历史。
- 模型输出严格校验，不可用、超时、无效 JSON 明确报错，不静默降级伪装真实分析。重要结论和训练答案由教师复核。
- 上限：家长30个档案，单档案50个预约绑定、200条业务记录、2000次普通幂等操作记录、2MB UTF-8状态；达到上限拒绝普通新写入，保留历史。撤销已有授权仍然可用，最多额外保留50个撤权回执，已经撤销的授权再次撤销不追加回执。当前没有另行归档导出的管理功能。
- Mock仅当前设备保存，无真实安全鉴权或跨设备同步。Mock的关联真实作业提交须改用API；演示身份只有一位可切换登录的教师，跨教师权限由服务端测试中的独立账户验证。

## 验证

单测覆盖同名隔离、越权、授权门槛/到期/撤销、并发与幂等、模型无效结构与迟到结果、原作业来源、修订训练、报告交接、消息分页及只读状态。

浏览器专项：`npm run test:e2e -- --config playwright.continuity.config.ts`，覆盖 Mock/API、桌面/手机及两主题；默认 `npm run test:e2e` 也包含该专项。Windows若默认TEMP不允许文件重命名，请把TEMP/TMP指向工作区临时目录；Vite忽略 `.test-temp`，避免监控浏览器锁定文件。

本轮不调用付费模型，不把协议夹具测试当作真实供应商联调；未验证微信真机、真实教学成效或公开部署。请使用虚构资料体验。
