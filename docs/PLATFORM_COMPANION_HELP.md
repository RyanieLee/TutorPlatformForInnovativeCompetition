# 领航云学堂 · 小书灵家长与学生服务指南

> 2026-10-22。本指南描述当前演示网站实际能力和模型接入条件，不声称真实资质认证、自动扣费或已上线客服。

## 给家长看的四步说明

1. **找老师**：首页选择科目、价格及授课方式；也可点「智能匹配」输入孩子学习需求。
2. **看资料**：比较老师的大学、专业、授课时间、价格和匹配理由。
3. **提交预约**：登录家长演示身份，在教师详情提交预约信息。
4. **查看进度**：「我的预约」看状态；「AI学习中心」有笔记、示例练习和解析。

## 小书灵可以回答什么？

| 主题 | 示例提问 | 行为 |
| --- | --- | --- |
| 软件帮助 | 平台怎么用？ | 返回简短四步指南，不索取个人信息 |
| 找家教 | 初中数学，预算100元，线下 | 本机整理需求，引导进入匹配页；不自动下单 |
| 学习答疑 | 一元一次方程怎么移项？ | 已配置服务端模型时可按步骤解释；未配置时只能提供已有笔记入口 |
| 作业批改 | 题目：2x+3=7；我的答案：x=3，请批改 | 已配置模型时检查题目与答案、说明错误和改进；无模型时明确不能判断 |
| 练习与出卷 | 怎么生成试卷？ | 引导到学习中心，区分固定示例与真正模型生成 |
| 预约进度 | 怎么取消预约？ | 告诉家长打开「我的预约」手动操作；不直接修改订单 |
| 老师入驻 | 家教怎么登记？ | 引导大学生家教在工作台填写并送审 |

## 批改答复规范

用户输入 **题目、学生作答**，可选填标准答案及年级/学科，建议先提示学生自行尝试。模型给出“结论 → 错误原因或正确依据 → 规范解法 → 修改建议”，缺少完整题目则先询问补充；不编造已读图片、上传文件或学生成绩。

聊天框暂时只接收文字；不支持通过聊天自动识别图片、语音、作业附件，且不会从「课次与作业」页面自动读取学生提交的内容。评阅建议只作辅导参考，不是正式教师评分。

## 两种工作模式

- **本机 Mock**：操作指南、关键词整理、原创笔记摘要；**没有真实通用 AI 解题与自动批改**。遇到批改请求会提示需要模型，绝不编造评分。
- **开发 API**：由服务器配置 `MATCH_MODEL_BASE_URL`、`MATCH_MODEL_NAME`、`MATCH_MODEL_API_KEY`；用户登录后才会调用模型。模型回答可能出错，重要题目由老师复查。模型没配置或服务异常仍可切回本机演示。

## 安全与测试重点

仅提交脱敏题目，不提交真实姓名、联系电话、住址、学校班级和证件。聊天不读取私人订单或修改账户，当前对话状态保存在内存且切换账户会清空。测试包括说明文案、作业引导、配置/未配置模型、角色隔离、长文本、隐私拦截、响应失败，以及桌面和手机响应式布局。
