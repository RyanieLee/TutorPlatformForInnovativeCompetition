# 在线演示部署设计

用户已授权发布最新网站，要求大陆可访问、使用已有 DeepSeek Key，优先免费托管，可为持续一两个月的地址支付少量域名费用。保留中文双主题及所有演示业务。

采用 EdgeOne 静态前端与 Node Functions。演示业务仍保存在访客浏览器；真实模型仅开放中文问答和文字作业批改。独立构建开关 VITE_DEMO_AI_GATEWAY 不影响现有本机 API 或原 hostedAssistant 模式。访问模型时输入演示口令，Key 仅通过云平台服务端配置。

接口仅连接固定 HTTPS DeepSeek 地址；校验输入、同源请求、口令与到期时间，限制输入和输出、单实例频率与并发。不把单实例计数宣传为全局账单上限。配置缺失或过期时关闭调用，错误消息不返回上游内容或密钥。图片识别本轮关闭，保留文字入口。

域名需核实注册状态和实际首年价格，再交给用户购买。自定义域名选择合适加速区域；大陆节点要求备案，未备案可先使用非大陆节点并实际检查大陆访问。无域名时中国站大陆预览链接3小时有效，不能当作长期交付。

交付必须区分代码测试、云端部署、真实模型调用和大陆访问验证。未完成登录、密钥配置或购买时，明确列出尚未完成事项，不生成虚构网址。
