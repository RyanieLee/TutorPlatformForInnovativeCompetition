# 云伴学持续教学设计

依据：用户已确认的作品介绍（文档 PR #40），以及本轮明确选择的 PR #39 基线。用户要求将介绍中的待实现功能接入最新 UI；保留绿色、Jenny 两套主题，中文交互，独立功能 PR，不合并 main。

## 方案与目标

沿用现有 Vue/uni-app、Fastify、SQLite、登录、预约、课次和管理员模型配置。把长期学情作为独立学生档案关联多个预约；预约仍是课次、沟通和试课的边界。相比按姓名拼接历史，这能区分同名学生；相比重建教学模块，这保留团队已有的不可变课次和附件权限。

提供家长多学生档案、试课记录与确认、分级授权、作业分析与针对训练、训练作答、教师备课报告、观察记录、家长确认的换师交接；另在预约加入站内文字沟通及通勤参考。页面复用已有布局和 ai-workspace 样式。

## 档案与权限

学生有独立 ID、归属家长、学习称呼、年级、目标和版本号。旧预约不会按姓名自动归档，家长明确绑定自己的预约。每个预约只能绑定一个档案。家长可查看自己的完整记录，管理员和无关教师不可读取。

关联教师在试课前只见称呼、年级、目标及其预约标识。教师提交试课观察后，家长确认试课，再主动授权 summary（已确认摘要）或 learning（作业、训练、已确认报告）。授权限定预约教师、有到期时间、可撤销；取消预约失效。教师不能自授权。所有写入服务端验证身份、角色、预约状态、版本；异步模型完成后重新验证授权与版本。授权不改变旧课次附件原有权限，撤销不能消除教师已经合法持有的资料。

换师交接由家长选择已确认报告，形成保留来源日期的快照摘要；新教师须完成自己的试课并获授权。家长可以同时撤销旧教师的云档案权限。没有批准的草稿不进入交接摘要。学习观察只描述可核对的事实与教学建议，不生成性格标签。

## 教学闭环

设计检查补充（实现者决定）：每次教学闭环固定一个已绑定、进行中的 bookingId。对应教师负责审核、报告和下一课；同时授权的其他教师仅能按授权读取已确认学习证据，不能修改该预约的记录。直接录入文字也必须选择预约。

家长可提交题目、作答、参考答案并明确同意发送模型；可关联真实作业提交 ID，服务端验证该提交属于已绑定预约并保存来源。模型使用 PR #39 的动态 managedChat，因此关闭管理员配置立即阻止新调用。原图片批改入口保留，长期档案以用户确认的文字为准，不长期保存原图。

模型返回严格校验的结构化结果：知识点、问题分析、教学建议、训练题（题目、参考答案、解析）。失败明确显示，不伪装真实分析。提供明确标注的固定示例，不调用付费模型。教师审核确认分析与训练后，家长提交训练答案；教师根据原答案及训练作答形成可编辑备课报告并确认，报告用于下一课草稿。报告中不捏造掌握率或提分效果，给出实际题数、作答和来源。下一课仍由教师在原编辑页检查时间、内容并发布，不自动发布。

## 数据和接口实现选择

实现者选择：独立 StudentArchive 表保存归属、revision 和受控 JSON 聚合；ArchiveBooking 表唯一关联预约；所有变更 expectedRevision + requestId，重复请求必须与原 payload 一致。状态通过纯 TypeScript 引擎，API 与本机演示共享；API 权限不能依赖前端。POST /api/student-archives 创建，GET 列表与详情，POST /:id/actions 执行有判别字段 type 的命令；GET /api/student-archives/bookings 为关联候选。DTO 按访问级别投影，不能先发全量数据再隐藏界面。响应都是既有 data/error 信封。

独立 namespace /api/booking-connections/:bookingId 提供文字消息与通勤。消息仅预约双方可读，待确认/进行中的预约可发，结束只读；有 requestId 去重和有界分页。页面可手动刷新，不承诺实时推送。通勤不使用学生精确住址，选择公共区域参考点、显示明确的直线距离和地图路线查询入口；没有路况或公交数据时不编造通勤分钟数。当前不新增外部付费地图服务。

容量和校验：每家长最多 30 档案，文本有界，单档案保留最多 200 个业务记录（到限明确提示归档/另建，不悄悄丢历史），模型每用户限流、请求失败不写半成品。模型提示只发送必要学习内容，不发送学生姓名、家长信息、地址、完整历史。来源由服务端确定，不信任客户端 source 字段。

有意义的测试覆盖同名不同档案、无关家长/教师/管理员越权、试课前最小投影、未确认不得授权、过期/撤销、异步撤权、版本冲突、幂等、畸形模型响应、真实提交归属、训练报告交接、消息越权和去重。运行根目录与 server 检查、构建及关键浏览器流程；检查两主题与手机宽度。外部真实模型调用、微信设备、真实教学成效单独说明，测试不会冒充这些验证。
