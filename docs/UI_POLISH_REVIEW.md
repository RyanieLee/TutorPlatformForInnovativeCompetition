## 本轮修改

- 外观名称统一为“浅蓝风”“绿色磨砂风”，保留已保存的内部主题标识。
- 绿色登录页改用浅绿磨砂底色，账户、密码有可见标签；输入框高56px，文字不再被原生控件高度挤压。
- 绿色主页主操作及价格筛选按钮缩小上下留白：桌面高36px、上下内边距6px；手机高40px、上下内边距8px，字号14–15px、行高20px。这是按用户要求收紧的尺寸。
- 智能匹配圆形箭头独立设置行高与双向居中，消除继承按钮行高造成的约7px下偏。
- 浅蓝页首logo使用完整SVG与连续底色，移除截图裁切造成的缺口。
- 悬浮AI问答历史获得明确高度和内部滚动，输入区保持可见，可向上翻阅旧消息。
- 入驻资料表单内部滚动，保存/提交操作在表单外保留；手机悬浮助手避让操作区。
- 待审核申请可以确认撤回为草稿，保留资料与照片，再修改送审。仅本人可撤回，已审核结果返回冲突；数据库用待审核状态条件更新并记录审计。
