# AI 接入与助手（PR 方案，暂不合并）

关联 #38。基于 main `5d04c4f`，独立分支 `feat/admin-model-assistant`。按负责人本次授权，先补管理员模型接入，再复用现有聊天、语音与图片辅导能力。

## 负责人接入 DeepSeek

1. 按项目原有说明初始化并启动后端、开发演示账户。前端使用 `VITE_DATA_MODE=api`、`VITE_API_BASE_URL=http://127.0.0.1:3001`，重新启动或构建 H5。不要在前端配置模型密钥。
2. 登录管理员账户 → 我的工作台 → **模型接入**。填写 `https://api.deepseek.com`、你账户可用的模型名称（默认 `deepseek-flash`）和 API 密钥。保存后密钥输入框清空；留空保存会保留原密钥，更换服务地址须重新输入密钥。
3. 点击 **测试连接**。请求会产生少量供应商用量；返回成功、模型名称和耗时，只验证文字接口。失败时显示脱敏错误，不会返回供应商响应或密钥。未保存的修改不能直接测试。
4. 开启 **启用模型服务** 并保存。新请求即时使用配置，无需重启。未启用时可以测试连接，但不会开放用户对话。
5. 若选用支持图片输入的模型，开启 **允许图片输入**，到完整对话中的“图片与学习工具”用脱敏示例单独测试。这个开关不是视觉能力检测结果。
6. 登录学生/家长或家教账户，点击右下角 **AI 助手**直接聊天；导航 **AI批改**进入独立文字批改页。填题目、自己的解法、可选参考答案，确认脱敏后提交。学生沿用现有“学生/家长”身份，不新增或伪造角色。

网页头部提供 **绿色玻璃 / Jenny 浅蓝** 两个外观选项，默认绿色玻璃，选择保存在当前设备，刷新或跳转页面后继续使用。两套外观共用最新业务与 AI 功能，不复制两套业务代码。主题切换限定 H5；小程序保留原有外观，本次只验证编译，未进行真机验收。

默认地址与模型名依据 2026-10-23 查阅的 [DeepSeek 官方接入文档](https://api-docs.deepseek.com/)、[视觉输入文档](https://api-docs.deepseek.com/guides/vision/)。模型名称由管理员填写，实际账户权限和能力以供应商为准。

## 保存与部署

- AES-256-GCM 加密配置默认保存在后端工作目录 `.ai-config/provider.enc`；首次保存自动生成同目录的 `provider.enc.key`（32 字节），目录与文件尝试使用仅当前账户权限。Windows 部署还应将该目录 ACL 限定为运行服务的账户。
- 也可设置 `AI_CONFIG_FILE` 指向持久化目录，并设置 `AI_CONFIG_ENCRYPTION_KEY` 为 **64 位十六进制随机值**（32 字节）。设置后由部署环境提供加密密钥，不生成本机 key 文件。更换加密密钥后旧配置无法解密，应重新填写或恢复原密钥。
- 加密保护的是配置内容；拥有服务器目录及 key 文件读取权限的人仍可解密。两者均不得提交 Git；容器部署需持久化保存并控制备份权限。本功能定位为现有单实例演示后端，未实现多实例配置同步。
- 默认只允许 `api.deepseek.com` 的 HTTPS 根路径或 `/v1`。其他兼容服务由部署人员通过 `AI_ALLOWED_HOSTS`（逗号分隔）明确添加，不能在网页任意填写内网地址。服务端拒绝跳转，不提供网页代理。
- 页面/API 从不回传密钥全文或后缀；不存浏览器 localStorage。修改配置记录审计动作，不记录密钥。退出/切换身份会清空表单，迟到响应不再显示。
- 管理员设置一旦保存，会覆盖本实例聊天与图片服务的旧 `MATCH_MODEL_*` / `HOMEWORK_MODEL_*` 配置；未保存管理员配置时保留旧环境变量行为。配置损坏时关闭托管模型，不悄悄回退。家教匹配、试卷生成与教学计划继续使用各自原配置，本 PR 不擅自切换这些服务。

## 产品范围

悬浮窗口适合简短学习问答与平台指引；完整页面保留语音和图片工具。学生侧侧重分步提示和知识点复习，家长侧侧重平台流程，家教侧提供备课入口。助手不会自动读取账户、订单或定位，也不能替用户预约、审核或修改成绩。

文字批改输出逐题判断、错因、建议和复习点。示例按钮仅填入文字，不生成假的模型反馈。没有配置时明确提示不可批改。结果不作为正式成绩，条件不足时应说明无法判断。聊天与批改复用既有限流、认证及上游超时/响应大小限制；模型错误不伪装成功。

后续可在本 PR 评审后独立考虑：经用户选取并授权的课程资料检索、批改历史/教师确认、逐字流式输出、会话列表与成本配额。当前不自动收集学习档案或持久化作业。

## 设计 brief 与验证

用户为学生、家长和家教；主要任务是获得及时帮助与可读的作业反馈。沿用绿色磨砂玻璃与纸张色，悬浮球用轨道与书页启发的简洁矢量图形；输入与结果分栏，手机纵向排列。重点是配置状态、清晰的主操作和正文阅读，减少拟人卡通、发光和多余装饰。

参考 UI/UX Pro Max 的教育产品检索、Vue 生命周期/行为测试和键盘焦点规则；保留既有品牌色，不照搬检索中的落地页 Hero 或 CTA 布局。Distinctive AI Design 按明确视觉方向直接实现并截图自查；使用 `prefers-reduced-motion` 关闭入场动画。

真实供应商联调留给负责人填入密钥后完成。仓库内测试仅使用虚构数据和受控协议响应，不证明模型答题质量或视觉识别准确率。浏览器验收与命令结果见本目录截图及验收记录。
