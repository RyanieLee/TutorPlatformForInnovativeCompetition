## 如何看到页面

首页点击“AI学习中心 · 各科笔记与智能出卷”，或顶部导航“AI学习中心”。本机Mock模式也可直接体验资料、笔记、22份示例练习、自测和导出。

```bash
npm ci
npm run dev:h5 -- --host 127.0.0.1
```

选择学段→科目→阅读笔记→围绕笔记出卷→先体验3道原创示例题→答题→核对选择题→显示答案解析→导出无答案/含答案TXT。电脑端可用浏览器打印，选择是否显示答案后再打印；可在打印对话框另存PDF。微信构建中外链和导出使用复制，不调用浏览器专有API。编译通过不代表微信真机验收完成。

## AI生成新试卷

先按C的SERVER_DEMO说明启动本地API；在未提交的server/.env中填写已有 MATCH_MODEL_BASE_URL、MATCH_MODEL_NAME、MATCH_MODEL_API_KEY。支持兼容Chat Completions的服务，共用此前需求解析配置；本机HTTP模型可不填密钥，远程必须HTTPS。EXAM_MODEL_TIMEOUT_MS默认30000，实际限制1000–45000毫秒。

另开终端运行API模式前端；Windows PowerShell：

```powershell
$env:VITE_DATA_MODE="api"
$env:VITE_API_BASE_URL="http://127.0.0.1:3001"
npm run dev:h5 -- --host 127.0.0.1
```

以家长、家教或管理员演示账户登录，选择主题、适用年级、基础/巩固/提高、3/5/8题，点击“AI生成新试卷”。只发送所选参数与本站原创笔记，不发送账户ID、作答内容、预约或学生资料。题目为练习草案，需要核对；结构校验不保证知识与答案完全正确。

未配置模型或上游失败会明确提示，不自动以示例冒充AI。用户可另行点击示例按钮；示例始终固定3题，难度和题量不随AI设置变化。没有真实供应商密钥，因此真实供应商连通性、生成质量、耗时与费用未实测。浏览器测试使用拦截的结构化结果；后端适配测试使用虚构传输，真实调用配置入口已交付。

## 数据与接口

- server/src/content/learning-topics.json为笔记的唯一数据源，前端只导入这份公开内容；shared/example-questions.json为固定示例题。答案在浏览器中可访问，自测不用于保密考试。
- GET /api/learning/status公开，仅返回enabled。配置齐全不代表模型上游可用。
- POST /api/learning/exams要求有效会话，严格输入{topicId,grade,difficulty,count}。年级与主题匹配，题量仅3/5/8。每账户每分钟最多5次，每来源15次；仅单进程开发限流。
- 返回data包含title/topicId/grade/difficulty/questions/totalPoints/source/createdAt。每题含id/type/stem/options/answer/explanation/points；choice四个不同选项且答案为A/B/C/D，short无选项。题量、重复题干、长度和结构均校验，分值由服务器统一为选择5分/简答10分。
- 模型输出流最多65536字节，不跟随重定向，失败不输出密钥或原始上游错误。身份信息不进入提示词。练习卷和作答仅留当前页面，没有新增数据库、浏览器历史缓存或数据迁移。
- 选择题按该份试卷的参考答案核对；简答题不自动打分，页面不把选择题得分说成全卷分数或能力评估。
