# 全站虚构演示数据

所有姓名、学生情况、作答、报告、沟通和治理记录均为虚构样例。预置分析不调用模型，不代表真实教育成效；模型设置页不注入密钥或伪造接入成功。

Mock网页首次使用业务服务时自动补齐数据，原有用户记录和后续修改保留。初始化版本标记为 `tutor-platform:learning-demo-seed:v1`，日常刷新不会重新生成授权或重置已处理状态。

API模式通过服务端既有 `npm run db:seed` 补齐同样的教学资料（需要先完成迁移、配置既有三个演示账户密码）。只在开发/演示数据库执行，生产环境拒绝执行。固定ID新增、按ID保留已有记录；重复执行不会重置授权、预约状态或教师修改。

Mock模式现有文件收交页面仍明确提示需要API，不能跨设备保存文件；独立AI批改与模型设置需要用户输入及有效API配置，不伪造实时模型结果。教师目录沿用24份合成教师资料。教学闭环原样例限定匿名初一数学，因此不向六年级预约灌入不适配的课程。

旧预览窗口需要重新打开新版HTML，浏览器存储会自动补缺。可先用家长查看林小禾的全部板块，再切换教师确认陈知远的报告、接受唐可欣的预约，最后切换管理员处理申请。
