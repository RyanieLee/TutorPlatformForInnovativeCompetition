# DeepSeek 问答与富文本修复

2026-10-23，延续 PR #39，只提交不合并。

## 文档核对与问题定位

已阅读官方中文[首次调用](https://api-docs.deepseek.com/zh-cn/)、[思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)、[对话协议](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)、[多轮对话](https://api-docs.deepseek.com/zh-cn/guides/multi_round_chat/)及[错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)。当前默认模型为 `deepseek-flash`，官方当前别名映射为 DeepSeek-V4.1-Flash-1017；管理员可手动改模型名称，不按问题自动选择模型。

官方当前模型默认启用 high 思考。旧实现只提供 700 tokens、默认 15 秒，截断或异常统一显示“服务暂不可用”；完整回答超过 3000 字符被拒绝，追问历史也只保留每条回答前 500 字符。这些限制足以导致较长学习讲解失败；没有保存用户截图中那次供应商原始响应，因此不能认定为那一次失败的唯一原因。公式未排版是另一个显示问题。

## 修复

- 普通助手对官方地址的 `deepseek-flash` / `deepseek-v4-pro` 明确使用非思考模式；其他兼容服务不发送 DeepSeek 专属参数，也不修改已保存的模型名称。
- 回答预算提高到 4096 tokens，默认等待 45 秒，服务端可配置 1–120 秒；前端相关请求等待上限 150 秒。管理员托管配置现在正确传递后端等待设置。本机仍为旧默认 15 秒时已更新到 45 秒，其他配置保留。
- 完整回答限 12000 字符、供应商响应限 64 KiB。保留完整回答用于最近四轮上下文；用户提问仍限 500 字，历史角色及隐私约束保留。
- 截断、认证失败、余额不足、限速、参数错误、繁忙、超时有不同提示。不会将推理内容冒充答案，不会自动再次发起计费请求。
- 网页聊天及独立文字批改反馈共用 Markdown / KaTeX 渲染器：标题、加粗、列表、表格、代码块、行内公式、多行方程组、分式与根号。支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。无效或未闭合公式保留可读内容，不使整条消息消失。
- 模型内容禁用原始 HTML，渲染后经 DOMPurify 过滤，KaTeX 关闭信任能力并限制展开与尺寸；代码不当作公式渲染，模型图片链接不会自动加载。公式及代码长行可在各自区域内横向滚动。小程序保留纯文本，未声称完成原生公式渲染。
- 一键启动器发现缺少新渲染依赖时会自动安装。当前工作区依赖已改为独立安装，旧版本的依赖目录不受影响。
