日期：2026-10-21。目标是电脑浏览器演示所需的稳定本地后端，沿用 Fastify、Prisma 和 SQLite。基线为 main dcb0432，PR #18 分页和 PR #17 独立设计预览均已合并；开发期间 PR #16 已由上游合入 main bcf1821；本轮同步该主分支后重新执行后端编译、54 项测试及 HTTP 验收。没有代改模型功能。

## 本轮完成

- 家长预约、家教接单、管理员申请和举报四类列表新增可选 status。状态和归属过滤在数据库分页前完成；总数与记录口径一致，保留原默认条数和 data/meta 结构。
- GET /api/admin/overview 返回申请、预约、举报各状态的全量统计和当前公开家教数量，只有管理员可读。聚合在同一事务内执行，不受第一页条数限制。
- 公开家教列表的计数与行查询改为同一事务；未知接口统一 404 error 格式。补充畸形 JSON、413、停用账户令牌失效和 CORS 回归。
- db:seed 改用 node --import tsx，解决先前 tsx CLI 创建 IPC 管道被运行环境拒绝的问题。迁移与测试直接调用已安装的 Node CLI，去除 npx 与 Windows shell 包装依赖。
- demo:setup 从模板生成本机 .env 和三个独立随机密码，已有 .env 不覆盖。生成内容不输出到日志、不提交 Git。
- API 默认只监听 127.0.0.1；PORT 校验；SIGINT/SIGTERM 优雅关闭 HTTP 和数据库。需局域网演示时自行设置 HOST 与 CORS，浏览器中的 localhost 始终指浏览器所在设备。
- db:backup 创建独立一致性 SQLite 快照，支持运行中 WAL 数据，拒绝覆盖源库或已有备份；默认备份目录不加入 Git。恢复采用全新路径，保留旧库供回退。
- test:demo 扩展为实际 HTTP、审核/预约/举报全流程、重复初始化/进程重启、WAL 快照/恢复、审计与实际 demo:serve 启动验收；沿用现有 CI 的执行入口。

没有修改前端页面、共享服务/类型或路由，没有修改数据库结构，因此无需新迁移。新增接口和可选参数写在 API_CONTRACT.md，以下内容作为 A/B/D 的交接记录，不表示已向成员发送消息。

## 你在 Windows 上启动

在项目 server 目录打开 PowerShell，首次运行：

```powershell
npm ci
npm run demo:setup
npm run demo:serve
```

在本机 VS Code 打开 server/.env 查看三个演示密码；账号分别是 demo.parent、demo.tutor、demo.admin。浏览器访问 http://127.0.0.1:3001/health，确认 data.status 为 ok。密码只用于本机演示。

另开终端到仓库根目录，启动已有网站：

```powershell
npm ci
$env:VITE_DATA_MODE="api"
$env:VITE_API_BASE_URL="http://127.0.0.1:3001"
npm run dev:h5 -- --host 127.0.0.1
```

打开前端启动日志中的地址，不是直接双击 Vue 源码。先家长登录预约，再家教登录接单，切回家长查看；管理员审核使用同一后端。原数据库的日常启动可用 npm start，新增修改后使用 demo:serve 重新编译。

备份命令：在 server 运行 npm run db:backup。完整恢复说明见 SERVER_DEMO.md。没有替你操作电脑、创建你电脑上的 .env 或启动你电脑上的服务。
