# 小书灵对话桌宠与西安订单地图

## 打开与演示

默认 `npm ci && npm run dev:h5`，首页右下角点击“小书灵”；顶部导航点击“订单地图”。家教/管理员工作台也有地图入口。默认Mock可体验文字对话、需求整理、本站笔记指引和固定虚构订单示例。

演示路径：小书灵 → 帮我找老师 → 带入匹配需求 → 核对需求/选点 → 预约时主动选择公共片区 → 登录后在订单地图查看。旧订单或未选择片区的订单仍显示在列表，不能凭空猜测位置。

## 对话桌宠

小书灵是项目网页/小程序内的CSS动画角色，不是ChatGPT应用桌宠。支持浮动、眨眼、暂停动作和系统减少动画偏好。家长公共布局、匹配页和家教/管理员工作台可打开对话面板；主要页面间同一账户保留当前应用内存中的对话，刷新、清空或切换账户会清除。聊天内容不写入本项目数据库或本机持久存储。

- 本机模式：明确标注“本机演示 · 非大模型”，只支持有限的需求关键词整理、本站原创笔记检索和操作指引，不声称是通用模型问答。
- 模型模式：复用服务端 `MATCH_MODEL_BASE_URL / MATCH_MODEL_NAME / MATCH_MODEL_API_KEY`，可选 `CHAT_MODEL_TIMEOUT_MS`（1000–30000ms，默认15000）。三种已登录演示角色可调用。没有配置模型密钥，真实供应商调用/质量/费用未验证。
- 只发送用户输入和最多最近四轮对话，每条历史最多500字；较长模型答复仅截取前500字用于下一轮上下文。当前页面、账户、订单、作答、成绩、坐标、课件不会自动加入请求。
- 对话不会执行预约、接单、取消、查询订单或修改账户。按钮只导航或主动把无私人信息的需求暂存在应用内存，再填入匹配页；仍需解析核对、选择和原预约流程。
- 模型失败显示明确错误；用户可主动切换本机演示，也可切回已配置的模型。基础个人信息拦截不保证识别所有敏感内容，请使用虚构学习需求。
- 后端每账户每分钟10次、来源每分钟30次内存限流；请求严格限定历史角色和长度，响应以字节流限制32768字节、正文3000字和超时，不向前端泄露上游原始错误。多实例/生产限流不在当前演示范围。

## 订单片区与权限

预约新增可选 `areaLabel`，只接受12个西安公共参考片区。用户必须在预约表单主动选择，或点击“填入匹配位置附近的公共片区”；后者只提取最近片区标签，不提交精确点位。默认“不在地图标注”。

新增SQLite迁移仅添加可空列，不重置数据库，旧记录保持NULL。API重试去重比较包含片区；同一个requestId改片区会409。实际部署应先备份并运行原db:init/migrate流程，勿重置已有记录。

订单地图的账户页：家长只能查看自己的订单，家教只能查看收到的订单，管理员查看全部；权限及归属取自服务端会话，忽略前端伪造的角色/家长ID。

地图专用接口不返回学生称呼、家长ID、联系方式或备注。列表展示科目、家教、方式、期望时间、当前家教参考价、状态和更新时间。参考价不是交易金额；片区点位不是住址、GPS追踪或路线。

## “实时”的实际含义

API模式每10秒轮询开发服务器的当前页，支持立即刷新，家教接单/家长取消后可同步状态。隐藏页面或浏览器后台暂停轮询；切换账户立即清除旧订单并丢弃过期响应。失败时保留上次数据并标明更新失败，认证失效则清空并引导登录；不自动以示例冒充服务器结果。

每页20条，有上一页/下一页及状态过滤；总数属于当前权限和筛选范围。地图明确只标注本页带片区的订单，同一片区聚合计数。颜色优先展示待确认/已接受，其余取组内最新记录；点击圆点或片区按钮查看对应订单。未标注订单保留在本页列表。

“虚构订单示例”是独立的固定12条合成样例，带清楚标识，既不生成假实时订单，也不混入账户订单/数据库统计。Mock账户订单只在当前设备同步，不模拟跨设备实时服务。

H5提供Esri在线道路底图；不可用时片区列表与订单信息仍可查看。小程序目前以片区列表显示订单，交互地图和真机验收仍需另行完成。公网前端/API发布依旧未完成，不把本机测试称为已上线。

## 验证

本机前端74项、B9项、后端94项测试通过；完整浏览器56例为44通过、12按模式跳过。包括对话来源、多轮请求、失败与模式切换、清空/暂停、匹配带入、示例分组/筛选、退出隔离。API端到端使用独立临时账户实际创建预约、家教接单，浏览器约10秒后自动读取接受状态，再手动刷新取消状态；模型UI响应为受控拦截，后端传输测试也使用虚构响应。

浏览器临时专用账户只在受保护的临时E2E数据库脚本中创建，不加入普通种子；沿用随机测试密码，避免污染演示账户登录限流。在线底图已在桌面/手机实际加载并截图，无横向溢出或脚本错误。整体验收及远程CI以本批PR为准。
