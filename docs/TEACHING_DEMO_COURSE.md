# 初一数学一元一次方程四课演示课程

预置演示课程，非真实授课或实时模型生成。匿名学生DEMO-STUDENT-01，教材版本和实际进度由教师核对。

总体目标：理解等式性质，规范求解和检验一元一次方程，将简单生活问题转化为方程，并分步骤解释思路。
先备条件：已学有理数及基本代数表达式；教材版本和实际进度由教师核对。

## 先备预诊断
- D1：计算 -3 + 8；答案：5；先比较绝对值，结果为正。
- D2：计算 -2 × 4；答案：-8；异号相乘得负。
- D3：化简 3x + 2x；答案：5x；同类项系数相加。
- D4：x = 2 是否为 3x + 1 = 7 的解？；答案：是；代入得 3×2+1=7。
- D5：x + 4 = 9，求 x；答案：x = 5；等式两边同时减4。

## L1 认识一元一次方程与等式基本性质

学习目标：分辨等式与方程，识别一元一次方程；用等式性质解简单方程并代入检验
知识点：未知数和方程的解；等式两边执行相同操作；除数不能为0

| 时间 | 教师活动 | 学生活动 |
| --- | --- | --- |
| 0–5分钟 | 用一个数加7等于15引入未知数。 | 尝试用字母表示未知数。 |
| 5–12分钟 | 讲解只含一个未知数且未知数次数为1的方程及解的含义。 | 比较等式、方程与一元一次方程。 |
| 12–22分钟 | 演示 x+7=15，两边同时减7，x=8并检验。 | 逐步说明两边的相同操作。 |
| 22–30分钟 | 演示3x=21，两边同除3得x=7；除数不得为0。 | 代入检验并解释为什么不能除0。 |
| 30–40分钟 | 观察学生独立练习过程并记录错误。 | 独立完成3题并验算。 |
| 40–45分钟 | 回顾等式性质，针对记录订正。 | 复述操作原则。 |

例题与解析：
- L1-E1：x + 7 = 15 → x = 8；两边减7，x=8；8+7=15。
- L1-E2：3x = 21 → x = 7；两边同除3；3×7=21。

独立练习与答案：
- L1-Q1：x + 9 = 17 → x = 8；两边减9。
- L1-Q2：5x = 30 → x = 6；两边同除5。
- L1-Q3：x − 6 = 11 → x = 17；两边加6。

课后作业：各写2道加减类、乘除类方程，完成求解与代入检验。
观察指标：两边是否执行同样操作；能否代入验算

## L2 合并同类项与移项

学习目标：正确合并同类项；解释移项来自等式两边相同操作，记录符号错误
知识点：同类项系数相加；移项与变号；负系数变形

| 时间 | 教师活动 | 学生活动 |
| --- | --- | --- |
| 0–5分钟 | 复习上一课等式性质。 | 口述相同操作的原则。 |
| 5–15分钟 | 演示3x+2x=20，合并得5x=20，x=4。 | 解释系数相加。 |
| 15–25分钟 | 演示5x−3=2x+9，两边减2x再加3，得3x=12，x=4。 | 说明每一步及移项变号。 |
| 25–37分钟 | 逐题记录5道练习的正误与错因。 | 完成下方5题并写步骤。 |
| 37–42分钟 | 根据已记录错误针对性纠正。 | 订正并指出错在何步。 |
| 42–45分钟 | 请学生解释移项变号的原因。 | 口头说明等式性质。 |

例题与解析：
- L2-E1：3x + 2x = 20 → x = 4；合并同类项得到5x=20。
- L2-E2：5x − 3 = 2x + 9 → x = 4；两边减2x加3得3x=12。

独立练习与答案：
- L2-Q1：4x + 3x = 28 → x = 4；7x=28，两边除7。
- L2-Q2：6x − 5 = 2x + 7 → x = 3；4x=12，两边除4。
- L2-Q3：5x + 7 = 2x + 16 → x = 3；3x=9，两边除3。
- L2-Q4：7 − 2x = x + 1 → x = 2；两边加2x减1，得6=3x。
- L2-Q5：9 − 4x = 2x − 3 → x = 2；两边加4x加3，得12=6x。

课后作业：完成移项专项5题，标出跨等号移动时的符号变化，并用两边相同操作解释。
观察指标：移项是否变号；合并同类项是否正确；是否漏检验

## L3 去括号与去分母

学习目标：运用去括号和去分母求解方程；解释分配律及等价变形的合法性
知识点：分配律；分母最小公倍数；等价变形

| 时间 | 教师活动 | 学生活动 |
| --- | --- | --- |
| 0–5分钟 | 复习移项和符号。 | 讲解一题移项过程。 |
| 5–15分钟 | 讲解2(x+3)=18，去括号或两边除2得x=6。 | 检查分配律。 |
| 15–27分钟 | 讲解(x−1)/3=(x+2)/6，两边乘6得2x−2=x+2，x=4。 | 解释为何要对两边每项乘6。 |
| 27–40分钟 | 观察分层练习并记录分配律、分母错误。 | 完成3题并逐步解释。 |
| 40–45分钟 | 订正并总结等价变形。 | 回代检验。 |

例题与解析：
- L3-E1：2(x + 3) = 18 → x = 6；两边除2得x+3=9。
- L3-E2：(x − 1)/3 = (x + 2)/6 → x = 4；两边乘6得2x−2=x+2。

独立练习与答案：
- L3-Q1：3(x − 2) = 15 → x = 7；两边除3得x−2=5。
- L3-Q2：(2x + 1)/3 = 5 → x = 7；两边乘3得2x+1=15。
- L3-Q3：2(x + 4) − 3 = 13 → x = 4；去括号得2x+5=13。

课后作业：去括号题2道、去分母题2道、等式变形步骤解释题1道；每题代入检验。
观察指标：分配律是否正确；能否使用分母最小公倍数；每步是否等价

## L4 应用题建模与单元总结

学习目标：读懂数量关系、设未知数并列方程；在实际情境中检查答案并解释变量
知识点：设未知数；数量关系建模；情境检验

| 时间 | 教师活动 | 学生活动 |
| --- | --- | --- |
| 0–8分钟 | 回顾方程求解步骤。 | 复述典型错误及纠正办法。 |
| 8–20分钟 | 示范根据数量关系列方程。 | 解释未知数和单位。 |
| 20–35分钟 | 引导独立完成情境题并口述变量意义。 | 完成3道情境题并检验。 |
| 35–42分钟 | 总结有证据的典型错误。 | 说明自己仍需巩固的步骤。 |
| 42–45分钟 | 完成单元自评并商定下一阶段目标。 | 按练习记录评价，不预测成绩。 |

例题与解析：
- L4-E1：某班42人，男生比女生多6人。女生有多少人？ → 女生18人，男生24人；设女生x人，x+(x+6)=42，2x=36，x=18。

独立练习与答案：
- L4-Q1：某班42人，男生比女生多6人，求男女生人数。 → 女生18人，男生24人；设女生x人，x+(x+6)=42；18+24=42且24−18=6。
- L4-Q2：商品打八折再优惠4元，实付60元，求原价。 → 80元；设原价x元，0.8x−4=60，x=80；80×0.8−4=60。
- L4-Q3：A类票比B类票少3张，合计17张，求A、B类票数。 → A类票7张，B类票10张；设A类票x张，x+(x+3)=17，x=7，B=10。

课后作业：完成5题单元小测（基础2题、移项1题、括号或分母1题、应用1题），并描述错误原因。
观察指标：列式准确性；解题过程是否规范；是否回代情境检验
