## 使用

双击项目根目录`一键启动真实AI测试.bat`，启动后打开`http://127.0.0.1:5173`。账户ID为`demo.admin`、`demo.parent`、`demo.tutor`，本机随机密码见启动器打开的`server/.ai-config/local-test-accounts.txt`。不要将该文件提交Git或分享。

此机器尚未保存真实模型配置。登录管理员后到“模型接入”填入自己的服务地址、可用模型与密钥，保存、测试连接、启用。没有配置时不伪造AI答复；本轮未调用付费模型或验证真实供应商效果。旧Sites预计域名不作为本轮交付地址。
