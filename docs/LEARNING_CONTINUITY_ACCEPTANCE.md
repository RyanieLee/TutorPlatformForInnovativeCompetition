## 已交付业务

| 作品介绍中的功能 | 本轮行为 |
| --- | --- |
| 学生云档案 | 家长建立独立学生 ID，明确关联预约，同名学生不自动合并；多学生、跨预约记录持久化 |
| 全程云伴学 | 脱敏文字作业 → 模型分析/固定示例 → 教师修订确认 → 针对训练 → 实际作答 → 可编辑确认报告 → 原课次编辑页备课草稿 |
| 教师学情总览 | 已确认报告、训练事实和可更正的教学观察；不生成性格或能力标签 |
| 试课与分级授权 | 对应教师记录试课，家长确认后主动授权摘要或详情、设置期限、随时撤销；服务端按权限投影 |
| 换师持续对接 | 家长选择已确认报告形成带来源/日期的交接快照，可同时撤销旧授权；新教师独立试课、授权 |
| 一对一线上沟通 | 预约双方私信、手动刷新、游标分页、幂等发送，结束只读，无关角色不可读 |
| 通勤便利 | 公共片区参考点直线距离与外部地图路线入口；不编造交通时间或公开住址 |
| 最新中文 UI | 复用现有布局、绿色/Jenny主题、桌面/手机适配；原图片批改与文字批改保留 |

操作说明见 [持续教学使用说明](learning-continuity.md)。真实提交来源由服务端核对，本轮没有自动解析所有附件格式；原图片批改用于主动识别，长期档案以明确输入的文字为准。

## 独立审查与修复

全分支独立审查发现并修复两项边界问题：普通操作回执/容量上限不能阻止家长撤权；动作名称只接受显式白名单，拒绝 JavaScript 继承属性名，防止基础权限教师消耗档案版本和容量。回归用例先复现失败，再验证修复；服务端完整套件最终通过。

普通写入上限为每档案200条业务记录、2000条幂等回执和2MB UTF-8状态；最多50个预约绑定。撤销有效授权可额外使用最多50条安全回执，重复撤销不再增加回执。达到上限后保留历史，不提供未实现的自动归档功能。

## 预览和真实能力边界

`scripts/package-offline-preview.cjs` 将 Mock H5 的脚本、样式与本地图片/字体合并成单文件 HTML。生成物已检查中文文档标记、内嵌脚本/资源及功能代码，内置浏览器的 URL 策略禁止打开 `file:`，因此未将单文件在内置浏览器中打开宣称为已验证。网页交互验收使用正常本地 HTTP 前端。

HTML 是本机功能演示，不启动后端、不调用真实模型。API 模式复用管理员模型接入；本轮仅使用受控协议响应，未调用付费模型、未证明真实供应商推理质量、真实教学成效或公网部署。Mock 只有一位可切换登录的演示教师；跨教师权限由服务端独立账户测试覆盖。撤权不会擦除教师已经合法获得的原课次资料。

当前列表上限（教师300个档案、候选1000个预约）未做生产规模压测；并发重复模型请求可能在数据库去重前产生两次供应商调用，不承诺外部计费恰好一次。使用说明和页面不把这些能力描述为已完成的生产保障。
